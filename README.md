## About

I'm a developer interested in practical software, AI-assisted workflows, and building products from the ground up. I enjoy moving between the interface, application logic, backend services, and the tooling that brings everything together.

- **Building:** [Numination](https://github.com/kraqinc/Numination), an AI-powered development workspace in active development.

- **Approach:** Build deliberately, test changes, learn from bugs, and improve one iteration at a time.
